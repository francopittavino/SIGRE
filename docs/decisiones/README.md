# ADRs (Architecture Decision Records)

Un archivo por decisión de peso (arquitectura, esquema de datos, elección de
librería/servicio con impacto difícil de revertir), propuesto por la skill
`cerrar-sesion` cuando corresponde.

**Nombre de archivo**: `NNNN-slug.md`, numeración secuencial con cero a la
izquierda (`0001-...`, `0002-...`).

**Plantilla**:

```markdown
# NNNN. Título

Fecha: YYYY-MM-DD
Estado: Propuesta | Aceptada | Rechazada | Reemplazada por NNNN

## Contexto

## Decisión

## Consecuencias
```

La skill `abrir-sesion` lista al empezar cada sesión los ADRs creados desde
la fecha de la última entrada de bitácora.
